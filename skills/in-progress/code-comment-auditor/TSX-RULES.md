# .tsx 专项规则

在通用覆盖规则之上，`.tsx` 文件追加以下规则：

- **React 函数组件（FC）一律视为公共函数**：必须有 TSDoc 块注释，coverage 100%。注释需包含：
  - 组件的核心用途——解决什么问题、出现在哪个界面或流程里
  - 每个 Props 的含义——用 `@param` 逐条说明它控制什么行为或展示
- **复杂 hook**：自定义 hook，以及逻辑不直观的 `useEffect` / `useMemo` / `useCallback`，按复杂逻辑规则加行内注释（why-not-what）。
- **JSX 条件渲染**：`&&`、三元表达式、`map` 中的分支，若条件并非显而易见，加行内注释说明"什么业务状态下会走到这个分支"。
